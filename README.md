# Customer Segmentation & Churn Pattern Analytics in European Banking

## Overview

This project is an interactive Streamlit dashboard developed to analyze customer churn patterns in a European banking dataset. It helps identify customer segments with higher churn rates based on factors such as geography, age, gender, balance, tenure, and customer activity.

## Features

- Interactive Streamlit Dashboard
- Customer Segmentation
- Churn Analysis
- Premium Customer Analysis
- Dynamic KPIs
- Interactive Charts and Filters

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Run the application:

```bash
streamlit run app.py
```
